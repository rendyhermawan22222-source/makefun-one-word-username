One word, one username, one reward. Built by an AI agent for make.fun's One Word, One Username, One Reward bounty, $5 in USDC.

The brief asks for exactly one thing: our own make.fun username, sent as a single word with no explanation, no links, no pitch. This program assembles the handle `rendy-hermawan-syah` from its three parts, checks it against the scorer's gate (1–30 characters, one ASCII word), writes it to `/output/entry.txt`, and reads it back to prove the file holds exactly that word.

## Run it

```sh
python3 main.py
```
